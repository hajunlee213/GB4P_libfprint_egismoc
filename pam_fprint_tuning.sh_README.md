# PAM Fingerprint (fprintd) Retry Count and Timeout Tuning (`pam_fprint_tuning.sh`)

This script removes the tight retry and timeout limits Ubuntu applies by default to fingerprint authentication (PAM fprintd) and restores the upstream standard values (3 tries, 30 s timeout).

---

## 1. Background and purpose

The official Ubuntu/Debian `libpam-fprintd` package ships its default profile `/usr/share/pam-configs/fprintd` with the options `max-tries=1 timeout=10 # debug` hard-coded.

* **The problem**:
  * If your finger is slightly off the sensor or at a bad angle and the first attempt fails, you are immediately switched to the password prompt.
  * If you do not touch the sensor within 10 seconds, it times out and moves on to the password prompt.
* **The package maintainer's intent**:
  * The limits are deliberately tight to cut the waiting time for users in terminals (`sudo`, `su`, etc.) who prefer typing a password over using a fingerprint.
* **The fix**:
  * For setups where the fingerprint is actually used, set the upstream `pam_fprintd` standard of **up to 3 tries and a 30 s wait**, which makes day-to-day use much more comfortable.

---

## 2. System paths modified or created

| Path | Role | Change |
| :--- | :--- | :--- |
| `configs/pam/fprintd` | PAM profile template in this repo | Defines `pam_fprintd.so max-tries=3 timeout=30` |
| `/usr/share/pam-configs/fprintd` | System PAM profile definition | Updated to `max-tries=3 timeout=30` |
| `/etc/pam.d/common-auth` | Common PAM authentication stack | Regenerated by `pam-auth-update` with `pam_fprintd.so max-tries=3 timeout=30` |

---

## 3. Key parameters and how they work

Upstream standard parameters documented in `man pam_fprintd`:

* **`max-tries=3`**:
  * The maximum number of fingerprint scan attempts allowed before authentication is reported as failed.
  * The upstream default is `3`; after one failure you can retry twice more, which helps a lot with misreads.
* **`timeout=30`**:
  * How long (in seconds) to wait for a fingerprint.
  * The upstream default is `30` seconds, giving you plenty of time to touch the sensor.

---

## 4. Requirements and dependencies

* **Packages**: `libpam-fprintd`, `fprintd`
* **Privileges**: root (`sudo`)

---

## 5. Running it

```bash
sudo ./pam_fprint_tuning.sh
```

---

## 6. Manual check and rollback

### Check that it is applied
```bash
grep "pam_fprintd" /etc/pam.d/common-auth
```
If the output contains `max-tries=3 timeout=30`, the change is applied.

### Roll back to the stock Ubuntu defaults (1 try, 10 s)
```bash
sudo sed -i 's/pam_fprintd\.so.*/pam_fprintd.so max-tries=1 timeout=10 # debug/' /usr/share/pam-configs/fprintd
sudo pam-auth-update --package
```
